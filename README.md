# Customer Retention Analytics

## Project Overview
This project analyzes customer retention and churn patterns using Python, SQL, Pandas, and Data Visualization techniques. The objective is to identify factors influencing customer retention and provide insights for improving customer loyalty.

## Tools & Technologies
- Python
- SQL
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Analyze customer behavior
- Identify churn trends
- Calculate retention metrics
- Generate actionable business insights

## Key Analysis
- Customer Churn Rate
- Retention Rate
- Customer Segmentation
- Monthly Retention Trends

## Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Querying
- Data Visualization
- Business Analytics
